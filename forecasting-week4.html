Classification Trees & Cross-Validation

Supply Chain Forecasting · BMME075 · March 3, 2026

SoloDecision treesROC curves10-fold CV
View PDF

Goal

Predict employee burnout risk with classification trees, then check which features really carry signal: demographics (job role, experience) or work behavior (focus hours, AI tool usage).

Dataset & Setup

Synthetic AI productivity data, target dBurnout built as a median split on burnout score (50/50 balanced). Trained rpart() with information-gain splits on a 70/30 train/test. Spec A: jobRole + experienceYears. Spec B: same + aiToolUsageHoursPerWeek, taskComplexityScore, focusHoursPerDay.

Key Analyses

  • Tree fit + information gain by hand, to verify which spec carves cleaner leaves
  • Confusion matrix on holdout + accuracy, sensitivity, specificity, precision, F1
  • ROC curves on train vs test, to spot overfitting
  • 10-fold CV with mean, SD and coefficient of variation per metric

  • Behavior beats demographics: Spec B splits first on focusHoursPerDay < 3.7, ignoring job role at the root. Information gain nearly doubles.
  • Same accuracy, different trade-off: both ≈0.54, but Spec A is conservative (specificity 0.906, sens 0.181), Spec B is balanced (sens 0.317, F1 0.411).
  • ROC barely above diagonal: both trees beat random guessing only slightly, and the two curves nearly overlap, so B's extra predictors don't shift the curve.
  • Mild overfitting: training ROC sits a touch above test in both specs, but the gap is small.
  • Spec B is more stable across folds: lower SD and CoV on every metric, so the means are more trustworthy.
Holdout metrics, Spec A vs Spec B
Same accuracy, opposite priorities , A avoids false alarms, B catches more true cases.
Pick by cost. If false negatives hurt more (missing at-risk employees), go with Spec B. If false alarms hurt more, Spec A keeps specificity high. Accuracy alone can't tell you which to pick.

Supply Chain Implications

Burnout drives turnover, errors and lost throughput. The useful insight isn't the prediction (AUC ~0.58, modest), it's which features carry signal: focus time and AI usage, not job title or tenure , and those are levers a manager can actually pull.
